PLM Studio

PLM Studio는 YouTube 채널 Sunset Park Pavilion의 운영자가 자기 PC에서만 쓰는 영상 제작·업로드 도구입니다. 운영자가 만든 음악 플레이리스트 영상을 YouTube API 서비스로 올리고 예약·관리합니다.

PLM Studio is a personal tool that the operator of the YouTube channel Sunset Park Pavilion runs only on their own PC to upload, schedule and manage the music playlist videos they create, using YouTube API Services.
