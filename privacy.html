1. 이 앱이 하는 일

PLM Studio는 운영자 본인의 YouTube 채널(Sunset Park Pavilion)에 운영자가 만든 음악 플레이리스트 영상을 올리고 예약·관리하기 위해 운영자 개인 PC에서만 실행하는 도구입니다. 이 앱은 YouTube API 서비스(YouTube Data API v3, YouTube Analytics·Reporting API)를 사용합니다. 이 앱을 쓰면 YouTube 서비스 약관에 동의하는 것이며, Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

2. 수집·이용하는 정보

  • 연결한 YouTube 채널의 채널 ID·채널 이름
  • 이 앱이 올린 영상의 메타데이터(제목·설명·태그·공개 범위·예약 시각·처리 상태)와 역검증 결과
  • 채널·영상 통계(조회수 등)의 원값 — 화면에 원값 그대로 보여 주기만 하고, 이 값으로 새 지표를 계산하거나 다른 데이터와 결합하지 않습니다
  • OAuth 토큰(액세스·갱신 토큰) — 운영자 영상의 업로드·수정·댓글 게시에만 씁니다
  • 이 앱은 시청자 개인정보를 수집하지 않습니다.

3. 저장 위치와 보호

모든 정보는 운영자 PC(로컬 작업 폴더)에만 저장합니다. OAuth 클라이언트 비밀과 갱신 토큰은 Windows DPAPI(현재 사용자 계정)로 암호화해 저장합니다. 외부 서버로 보내지 않습니다.

4. 보관 기간

  • YouTube API로 받은 값(영상 상태·통계 등)은 받은 날부터 30일 안에 갱신하거나 삭제합니다.
  • Analytics·Reporting 데이터는 30일마다 인가가 유효한지 확인하고, 인가가 없으면 더 이상 보관하지 않습니다.
  • 앱이 만든 입력(직접 쓴 제목·설명 원문, 파일 해시, 업로드 기록)은 운영 기록으로 보관합니다.

5. 권한 철회와 삭제

  • 앱의 설정 > YouTube 연결·발행 > 연결 해제를 누르면 토큰을 폐기(revoke)하고 API로 받은 데이터를 지웁니다.
  • Google 계정 권한 페이지에서도 이 앱의 접근을 철회할 수 있습니다.
  • 철회를 감지하면 7일 안에 이 앱이 저장한 API 데이터(캐시·통계)를 삭제합니다.

Effective date: 2026-10-11 · Operator: Operator of the Sunset Park Pavilion channel · Contact: GitHub issues

1. What this app does

PLM Studio is a tool that runs only on the operator's own PC to upload, schedule and manage music playlist videos created by the operator on the operator's own YouTube channel (Sunset Park Pavilion). This app uses YouTube API Services (YouTube Data API v3, YouTube Analytics and Reporting APIs). By using it you agree to the YouTube Terms of Service; Google's handling of data is governed by the Google Privacy Policy.

2. Information we collect and use

  • The connected channel's ID and title
  • Metadata of videos uploaded by this app (title, description, tags, privacy status, scheduled time, processing status) and verification results
  • Raw channel/video statistics (such as view counts) — displayed as-is only; we do not compute derived metrics or combine them with other data
  • OAuth tokens (access/refresh), used only to upload, update and comment on the operator's videos
  • This app does not collect any viewer personal data.

3. Storage and protection

All data stays on the operator's PC (local workspace). The OAuth client secret and refresh token are encrypted with Windows DPAPI (current user). Nothing is sent to third-party servers.

4. Retention

  • Values received from YouTube API Services are refreshed or deleted within 30 days.
  • Authorization for Analytics/Reporting data is re-checked every 30 days; without valid authorization the data is no longer stored.
  • Inputs created by this app (our own titles/descriptions, file hashes, upload records) are kept as operating records.

5. Revoking access and deletion

  • Use Settings > YouTube > Disconnect (revoke) in the app to revoke tokens and delete API data.
  • You can also revoke access at the Google Account permissions page.
  • After revocation is detected, API data stored by this app (cache and statistics) is deleted within 7 days.

6. Contact

Please reach us via GitHub issues.
